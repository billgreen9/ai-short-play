# 转场枚举

只允许以下值，写入 `transition`：

| 值 | 含义 | 约束 |
| --- | --- | --- |
| `cut` | 硬切 | 默认。相邻镜头信息变化大时使用 |
| `smash_cut` | 冲击切 | 反转瞬间，一集最多 2 次 |
| `match_cut` | 匹配切 | 物体/动作形状相似时 |
| `whip_pan` | 甩镜转场 | 追逐或时间跳跃，一集最多 1 次 |
| `fade` | 淡入淡出 | 仅用于集末或回忆入口 |
| `jump_cut` | 跳切 | 压缩重复动作，不要用于情绪高潮 |

禁止：叠化超过 0.5 秒、无动机闪白、连续 3 个 fade。
